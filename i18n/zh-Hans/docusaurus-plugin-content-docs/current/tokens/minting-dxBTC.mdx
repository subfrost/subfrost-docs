# dxBTC 的铸造与销毁

:::info 规划中
dxBTC 仍在规划中，尚未上线。目前还无法铸造或销毁 `dxBTC`，也没有相应的公开命令。本页此前介绍的 `subfrost-cli` 命令已停用，无法再使用。
:::

## 预期流程

### 铸造 `dxBTC`

dxBTC 上线后，存入的资产将首先转换为 `frBTC`。随后，铸造操作将把这些 `frBTC` 锁定在 dxBTC alkane 中，并向您的 Bitcoin 地址铸造 `dxBTC`。

### 销毁 `dxBTC`

销毁操作将销毁您的 `dxBTC`，并向您的 Bitcoin 地址解锁 `frBTC`，之后您可以将其解包为 BTC。
