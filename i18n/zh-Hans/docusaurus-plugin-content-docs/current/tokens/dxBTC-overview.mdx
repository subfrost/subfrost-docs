# dxBTC 概述

:::info 规划中
dxBTC 仍在规划中，尚未上线。目前无法铸造或购买 dxBTC。
:::

## Bitcoin L1 上的生息 BTC

`dxBTC` 是一种规划中的、将基于 SUBFROST 生态系统构建的生息合成 Bitcoin 资产。它旨在为 Bitcoin 持有者提供一种以信任最小化和去中心化方式赚取可持续收益的途径。

在实践中，这将是用户用 BTC 赚取 BTC 收益的最简单方式：

1. 用户将签署**一笔** Bitcoin 交易，将原生 **BTC** 质押到 SUBFROST 收益金库中。用户将收到 `dxBTC`，代表其质押的 BTC。
2. 其 BTC 将被封装为 `frBTC`，并部署到 Bitcoin L1 上的市场中性 LP 策略和超额抵押借贷协议中，无论 BTC 价格如何变动都能赚取收益。
3. 该收益随后将以原生 **BTC** 的形式返还给质押者，用户可以随时查看。
4. 用户将签署**一笔** Bitcoin 交易以解除质押其原生 **BTC** 并销毁其 `dxBTC`。
![dxBTC diagram](../Diagrams/dxBTC_example.png)

这些收益金库将部署在 Alkanes、Arch、BRC 2.0 以及任何其他在 Bitcoin 主网上启动的可编程生态系统上。

这种经济模型在 Ethereum 和 Solana 等其他区块链上**已经得到验证**，并且可以为终端用户*大幅简化*。

## 它是如何运作的？`frBTC` + 收益

在其核心，`dxBTC` 将是一个锁定 `frBTC` 的 alkane。SUBFROST 治理随后将作为去中心化策略师，将锁定的 `frBTC` 部署到各种保守的收益生成策略中。

这些策略可能包括：

*   **为去中心化交易所提供流动性：** `frBTC` 可用于为 `frBTC`/`wBTC` 等 delta 中性 LP 或去中心化交易所上的其他交易对提供流动性，赚取交易费用。
*   **借贷：** `frBTC` 可以在去中心化的超额抵押借贷平台上借出以赚取利息。
*   **跨链策略：** `frBTC` 可以无信任地桥接到其他区块链生态系统，如 Hyperliquid，参与收益耕作机会。

这些策略产生的利润随后将分配给 `dxBTC` 持有者，使他们能够在保持对 BTC 完全敞口的同时赚取被动收入。这将为 Bitcoin 持有者提供一种无需出售资产或信任中心化托管方即可让资产发挥作用的方式。

## SUBFROST 治理的角色

**SUBFROST 治理** 将在 `dxBTC` 中发挥至关重要的作用。治理将负责：

*   **选择和管理收益生成策略：** 治理将研究、审查并选择最有前景和最安全的收益生成策略，用于锁定的 `frBTC`。
*   **监控和再平衡：** 治理将持续监控所选策略的表现，并根据需要重新平衡投资组合，以优化收益和管理风险。
*   **分配利润：** 治理将确保收益生成策略产生的利润公平地分配给所有 `dxBTC` 持有者。

通过将 SUBFROST 的安全性和去中心化与 DeFi 的收益生成潜力相结合，`dxBTC` 旨在为 Bitcoin 持有者提供一个增长财富的强大新工具。
