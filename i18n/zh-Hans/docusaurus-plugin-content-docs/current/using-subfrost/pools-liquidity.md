# 资金池与流动性

SUBFROST 上的每一笔交换都是与**流动性池（liquidity pool）**进行交易：这是一个由任何人都可以贡献的、包含两种代币的共享储备。当你提供流动性时，你会向资金池中存入一对代币，并赚取该资金池产生的交换手续费的一部分。

## 工作原理

- 一个资金池持有两种资产（例如 DIESEL 和 frBTC）。价格会随着交易自动调整，因此你总能找到交易对手方。
- 当你添加流动性时，你会获得一个代表你在资金池中份额的 **LP 仓位（LP position）**。
- 每当发生交换，都会产生手续费并累积到资金池中，因此你的仓位价值会随时间增长。
- 你可以随时通过赎回 LP 仓位，取回你的流动性（以及累积的手续费）。

## 交换手续费，以及你能赚到什么

在标准 AMM 资金池中，一笔交换默认支付 **1%** 的手续费，分为两部分：

| 份额 | 费率 | 去向 |
| --- | --- | --- |
| 流动性提供者 | 0.8% | 进入资金池，累积到你的仓位中 |
| 协议 | 0.2% | 永久归入 AMM 协议 |

因此，在这类资金池中，**作为流动性提供者，你可赚取经由你的资金池成交的交易量的 0.8%**，按你在其中所占份额的比例分配。

:::warning BTCUSD 资金池的收费方式不同

frUSD/frBTC 资金池是 CryptoSwap 资金池，而不是标准 AMM 资金池，上述数字并不适用于它。

它的手续费在 **0.2% 到 0.8% 之间动态变化**，取决于一笔交易使资金池失衡的程度：使资金池趋于平衡的交易支付较低费率，使其失衡的交易支付较高费率。它还带有 **50% 的管理费（admin fee）**，因此资金池所收取的手续费中有相当一部分归入协议，而不是累积到你的仓位中。

目前这两个数值都无法从资金池合约中读取：能够公开手续费参数的视图尚未部署。请在交易前先获取报价，并且只把「0.8% 归流动性提供者」当作关于标准资金池的事实。

:::

## 提供流动性

1. 在兑换页面点击 **Liquidity（流动性）**，即可向资金池添加仓位。
2. 在 **Add（添加）** 标签页中，选择你要提供流动性的交易对。
3. 按照资金池的比例存入两种代币。应用会为你自动填入配对的数量，并显示 **Minimum Deposit（最低存入量）**。
4. 确认并签名。此时你已持有一个 LP 仓位，并开始赚取该资金池交换手续费的一部分。

## 移除流动性

1. 在兑换页面点击 **Liquidity（流动性）**，切换到 **Remove（移除）** 标签页。
2. 选择你要移除的 **LP 仓位**。
3. 设定 **Amount to Remove（移除数量）**。应用会按当前储备量报价，显示两种代币各自的 **Minimum Received（最低可得）**。
4. 确认并签名。你在资金池中的份额，连同它累积的手续费，会回到你的钱包。
