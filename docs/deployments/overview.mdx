# Deployments

This is the address book. Every SUBFROST system that is live on Bitcoin mainnet, what
its contract id is, and where to look at it.

Every id and address on this page was read back from Bitcoin mainnet on **2026-10-04**, at block **969,906**. Re-check instructions are at the bottom of each page.

Alkanes contracts are identified by a pair `block:tx`. That pair is the address: it is
what you pass to a view call, and it is what the explorer resolves. An id is permanent
once deployed.

:::tip[Verify before you integrate]
Nothing here requires trust. Every id below answers a view call that identifies it,
and the last section of this page shows the one command that checks them all. If a
value in these docs ever disagrees with the chain, the chain is right and this page
is stale - please open an issue.
:::

## Checking this page against the chain

Every alkanes contract that implements the token ABI answers opcode `99` with its
name. That is the cheapest possible identity check, and it is how the table above
was built:

```bash
RPC=https://mainnet.subfrost.io/v4/subfrost/jsonrpc

for id in 2:0 32:0 32:1 4:1776 2:92949 4:9000 4:9010 4:7782 2:77087 2:80663 4:866; do
  printf '%s  ' "$id"
  alkanes-cli -p mainnet --jsonrpc-url "$RPC" alkanes simulate "$id:99" \
    | grep -oE 'Data: 0x[0-9a-f]*' | sed 's/Data: 0x//' | xxd -r -p
  echo
done
```

At block 969,906 that prints `DIESEL`, `frBTC`, `frSIGIL`, `frUSD`, `frUSD-MINT`,
`DOOMACLE`, `TUNDRACLE`, `FIRE Manual Price Oracle`, `DIESEL / frBTC LP`,
`FIRE / frBTC LP`, `cFIRE-SIGIL`.

Contracts that are not tokens - the treasury at `2:96782`, the pool at `4:1778`,
the factory at `4:65522` - return empty for opcode `99`. That is expected: they
never implemented the token ABI. Identify those by the view calls documented on
their own pages, not by asking them their name.
